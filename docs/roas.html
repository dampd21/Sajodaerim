광고 ROAS 분석

광고 성과를 분석하고 최적화하세요

광고분석 (일반+메타) 사용법

펼치기

네이버, 메타, 구글 등 다양한 광고 플랫폼의 성과 데이터를 업로드하여 통합 분석할 수 있습니다.

데이터 업로드 방법

  1. 템플릿 다운로드
    광고분석 페이지에서 통합 템플릿을 다운로드합니다.
  2. 데이터 입력
    템플릿에 맞게 날짜, 캠페인명, 광고유형, 지출액, 노출수, 클릭수, 전환수, 매출액을 입력합니다.
  3. 파일 업로드
    작성한 Excel/CSV 파일을 클릭하여 업로드합니다.
  4. 분석 결과 확인
    자동으로 계산된 ROAS, CTR, CPA 등 핵심 지표와 캠페인별 성과를 확인합니다.

광고유형 구분

매출형(sales)은 ROAS 기준으로, 잠재고객(lead)은 CPL 기준으로 성과가 정렬됩니다.

주요 기능

  • 핵심 지표 대시보드 - ROAS, CTR, CPA, CVR, 총 지출/매출을 한눈에 확인
  • 일별 트렌드 차트 - 날짜별 성과 변화를 차트로 시각화
  • 캠페인별 순위 - ROAS 또는 CPL 기준으로 캠페인 성과 순위 확인
  • 리포트 내보내기 - 분석 결과를 Excel/CSV 파일로 다운로드
